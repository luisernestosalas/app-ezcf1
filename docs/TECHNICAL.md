# Documentación Técnica - CRM con Clientes y Notas

## Información General
- **Aplicación**: Sistema CRM para gestión de clientes y notas
- **Stack Tecnológico**: HTML + JavaScript
- **Repositorio**: https://github.com/luisernestosalas/app-ezcf1
- **URL de Producción**: https://app-ezcf1-h88tytdal-luisernestosalas-2775s-projects.vercel.app

## Arquitectura del Sistema

### Frontend
- **HTML**: Estructura de la interfaz de usuario
- **JavaScript**: Lógica de negocio del lado del cliente
- **Características**:
  - Aplicación web de página única (SPA)
  - Interfaz responsive
  - Gestión de estado en el navegador

### Plataforma de Despliegue
- **Vercel**: Hosting y deployment automático
- **Integración continua**: Conectado con repositorio GitHub
- **SSL**: Certificado incluido por defecto

## Funcionalidades Principales

### Gestión de Clientes
- Crear nuevos clientes
- Visualizar lista de clientes
- Editar información de clientes existentes
- Eliminar clientes del sistema

### Sistema de Notas
- Agregar notas a clientes específicos
- Visualizar historial de notas
- Editar notas existentes
- Eliminar notas
