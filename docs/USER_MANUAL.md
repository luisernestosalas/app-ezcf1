# Manual de Usuario - CRM con Clientes y Notas

## ¿Qué es esta aplicación?
Es un sistema simple para gestionar clientes y sus notas. Te ayuda a organizar la información de tus clientes de forma fácil.

## Cómo acceder
Ingresa a: https://app-ezcf1-h88tytdal-luisernestosalas-2775s-projects.vercel.app

## Funciones principales

### 📋 Ver clientes
- Al abrir la app verás la lista de todos tus clientes
- Cada cliente muestra: nombre, email, teléfono y empresa

### ➕ Agregar cliente nuevo
1. Haz clic en "Nuevo Cliente"
2. Completa los campos:
   - **Nombre**: Nombre completo del cliente
   - **Email**: Correo electrónico
   - **Teléfono**: Número de contacto
   - **Empresa**: Empresa donde trabaja (opcional)
3. Haz clic en "Guardar"

### ✏️ Editar cliente
1. Busca el cliente en la lista
2. Haz clic en "Editar"
3. Modifica los datos que necesites
4. Haz clic en "Guardar cambios"
