# CRM con Clientes y Notas

Una aplicación web simple y efectiva para gestionar clientes y sus notas asociadas, desarrollada con tecnologías web estándar.

## 🚀 Demo en Vivo

Accede a la aplicación: [https://app-ezcf1-h88tytdal-luisernestosalas-2775s-projects.vercel.app](https://app-ezcf1-h88tytdal-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ Gestión completa de clientes (crear, editar, eliminar)
- 📝 Sistema de notas vinculadas a cada cliente
- 🔍 Búsqueda y filtrado de clientes
- 💾 Almacenamiento local en el navegador
- 📱 Interfaz responsive y fácil de usar
- ⚡ Carga rápida sin dependencias externas

## 🛠️ Stack Tecnológico

- **HTML5** - Estructura y marcado
- **JavaScript** (Vanilla) - Lógica de la aplicación
- **CSS3** - Es
